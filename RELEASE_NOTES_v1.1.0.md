A big update to Vndex 📚

## Install (Android)

1. Download **Vndex-v1.1.0.apk** below.
2. Open it on your phone. If asked, allow installing apps from your browser or files app.
3. If Google Play Protect warns about an unknown app, tap **More details** → **Install anyway**.

**Updating from 1.0.0?** This version is signed with a new key, so Android can't install it over 1.0.0. In 1.0.0 there's no backup yet, so note down anything you want to keep, uninstall 1.0.0, then install this one. From now on, updates install normally, and you can use **Settings → Data and storage → Back up now** to keep your library safe.

## What's new

- **Collections**: your own groups like Favorites, each with its own tab
- **Backlog roulette**: "What should I play next?" with a length filter
- **Home screen widget** showing what you're currently playing
- **Backup and restore** to a single file
- **English availability** on VN pages, plus an "Available in English" filter
- **Related VNs**, **staff** and **memorable quotes** on VN pages
- Tap a **studio** or **staff member** to see more of their VNs
- **Undo** when removing a VN, and a link to each VN's VNDB discussions

Vndex is an unofficial app using data from VNDB.org. Your lists stay on your device.
